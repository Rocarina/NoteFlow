# 📝 NoteFlow

A modern **Full-Stack Note Management Application** built using **HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, and JWT Authentication**. NoteFlow helps users securely create, organize, edit, and manage their notes through a clean and responsive interface.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Rocarina/NoteFlow.git
```

Go to project directory

```bash
cd NoteFlow
```

---

## Backend Setup

Navigate to backend

```bash
cd backend
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

Run the backend

```bash
npm start
```

or

```bash
npm run dev
```

---

## Frontend Setup

Open the `frontend` folder and launch `index.html` using Live Server or any local web server.
